# Devtrainer v0.1.0

The first public version of Devtrainer: programming practice in your terminal, with worked lessons, real code exercises and spaced review.

## Install

```sh
brew install kevnnard/tap/devtrainer
devtrainer --version
devtrainer
```

Homebrew builds from source. The release includes a source archive rather than precompiled binaries or bottles. The installed package is verified on Linux; macOS runtime verification is not part of this release.

## What's included

- **14 tracks:** logic & algorithms, Go, Python, JavaScript, TypeScript, Java, C#, Rust, Git, Linux, Docker, SQL, software architecture and AWS.
- **106 concepts and 492 practice items**, including **82 exercises that run real code**.
- Worked lessons, predictions, explanations and optional error-on-purpose steps.
- Spaced review per concept, prerequisite unlocking, mastery tracking and local SQLite progress.
- Section exams in Go, Python, JavaScript and SQL, with an 80% pass mark and saved results.
- An optional AI tutor and content drafts through your configured `pi` provider. Core practice does not require AI.

## First steps

Start a session from Home. In a code exercise, **Ctrl+R** runs your answer and **Ctrl+T** shows a hint. In Tracks, **x** starts the selected section's exam once every concept is at least learning. Press **?** for help.

Code exercises need the corresponding local toolchain; SQL uses built-in SQLite. Missing-toolchain exercises are skipped without grading. Run `devtrainer validate` to inspect availability.

## Important limits

- Code runs locally with your permissions and environment. **This is not a sandbox: do not submit untrusted code.**
- TypeScript execution checks output, not types. Node strips supported type syntax; the supplied exercises also have Deno type-check tests.
- Long error and solution previews can be truncated in small terminals.
- The SQL exercise engine is SQLite; some explanatory lessons discuss PostgreSQL.
- AI use may send your exercise and answer to your chosen provider and may incur its costs.
